# 🚀 À propos

Ju-Conception est un studio créatif indépendant basé en Normandie.

J'accompagne particuliers, associations et professionnels dans la création de leur présence numérique grâce à une approche mêlant design, développement, communication et intelligence artificielle.

Mon objectif est simple :

> Transformer des idées en projets concrets, utiles et durables.
